用你自己的声音

推荐走火山引擎控制台的声音复刻（效果最佳，音色只在平台侧训练一次）：

  1. 登录火山引擎控制台 → 语音技术 → 声音复刻
  2. 上传 10-20 秒安静环境的清晰人声录音，等待训练完成
  3. 复制 S_ 开头的声音 ID
  4. 回到「TTS 工坊」→ 引擎选 volcengine → voice 填这个 ID → 任意文案都是你的声音

官方预置音色（如 zh_female_cmlccs_moon_bigtts）需在控制台对音色开通（多数 0 元）。
